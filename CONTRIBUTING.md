# Contributing

Run the local setup in README.md, then run `npm test` and `npm run build` before submitting changes. Keep dependencies small, SQL parameterized, API authentication mandatory in production, and migrations additive. Include meaningful tests for ordering, validation, persistence or security changes. Do not commit local D1 files, task backups, credentials, or personal deployment configuration. Describe the user-visible behavior and validation in a pull request. A license must be selected before this project accepts public contributions under an open-source license.
